## 🧭 About Ainux

**Ainux is a founder-led portfolio of independently developed software products.**

I build software products and digital infrastructure through systems architecture, AI-assisted engineering, and hands-on validation.

Ainux products span digital-asset infrastructure, business operations, digital identity, publishing, browser-based utilities, and community platforms.

Ainux is **not one monolithic application**. Each product has its own purpose and architecture.

> **🎯 Current priority: AinuxVault**
>
> Development of the other products is paused while I concentrate on AinuxVault’s validation, integration readiness, and commercialization. This does not mean that every existing product or public service has been discontinued.

## 🔐 Spotlight — AinuxVault

### Digital-Asset Infrastructure for Organizations and Developers

<img src="https://img.shields.io/badge/Source-Proprietary-9D85FF?style=flat-square&labelColor=182335" alt="Proprietary source" />
<img src="https://img.shields.io/badge/Stage-Local_prototype-00C9A7?style=flat-square&labelColor=182335" alt="Local prototype" />
<img src="https://img.shields.io/badge/Demonstrations-Test_%2F_Dev_Networks-F1CA75?style=flat-square&labelColor=182335" alt="Test and development network demonstrations" />

<br /><br />

**AinuxVault is a proprietary infrastructure product for applications that need to organize wallets and execute digital-asset operations across multiple blockchain ecosystems.**

It is being developed as an integration layer for digital-asset platforms, fintech applications, and institutional workflows—not simply another consumer wallet.

### Product Direction

| Area | Direction |
| :--- | :--- |
| 🏢 Organization | Organization-scoped accounts, vaults, and wallets |
| ✍️ Signing | Distributed transaction signing |
| 🌐 Transactions | Multi-chain transaction workflows |
| 🔌 Integration | Developer APIs and integration tooling |
| 📊 Operations | Operational visibility and transaction records |
| ⚙️ Deployment | Configurable deployment and governance options |

### Current Status

A working local prototype exists, with demonstrated signing and asset-transfer workflows across **five blockchain ecosystems on test/development networks**.

The next stage focuses on developer tooling, deployment readiness, broader testing, independent security review, and institutional pilot integration.

**Not all planned capabilities are production-ready. No Mainnet launch or completed independent security audit is currently claimed.**
